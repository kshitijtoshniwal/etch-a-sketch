# Etch-a-Sketch

A browser-based Etch-a-Sketch built with HTML, CSS, and JavaScript.

## Features

- Draw by hovering over the grid cells.
- Choose a custom grid size (1–100 squares per side).
- Clear and rebuild the grid when changing its size.
- Fixed drawing area regardless of grid size.

## Built With

- HTML5
- CSS3
- JavaScript (Vanilla)

## Getting Started

1. Clone this repository:

   ```bash
   git clone git@github.com:kshitijtoshniwal/etch-a-sketch.git
   ```

2. Open the project folder.
3. Open `index.html` in your browser.
